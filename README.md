# Notes App

## Features

- **Create & edit notes** — title, content, and tags editable inline
- **Tags** — add multiple tags per note, displayed as chips
- **Archive / Restore** — move notes to an archived view and restore them
- **Search** — filter notes by title, content, or tags with 300ms debounce
- **Persistence** — notes saved to `localStorage`, no backend required
- **Responsive** — bottom navigation and FAB button on mobile

## Tech stack

- React 19 + TypeScript
- Vite
- SCSS (component-scoped stylesheets)

## Getting started

```bash
npm install
npm run dev
```
